# Salina Tarot — CyberGirlfriends

Trois cartes. Une question. Une histoire. / สามไพ่ หนึ่งคำถาม หนึ่งเรื่องราว

An elegant French-luxury tarot web app prototype built around a real Tarot de Marseille deck (78 cards):

- Real crypto-random shuffle & 3-card draw, locked once chosen
- Bilingual UI (Thai / French)
- AI reading powered by Claude ("Madame Salina"), interpreting only the locked draw
- Reading history saved locally

## Run it
Just open `salina-tarot.html` in a browser — no build step needed.

> Note: the "Ask Salina" AI reading feature requires a Claude API connection and will not work when this file is hosted standalone (e.g. on GitHub Pages) without a backend proxying the API key.
